# Facio – installation / installers

Facio är ett program för att skriva fakturor, spara dem som PDF och markera dem som betalda. Dina uppgifter sparas på din egen dator.
*Facio is a program for writing invoices, saving them as PDFs and marking them as paid. Your data is kept on your own computer.*

Den här sidan innehåller bara installationsfilerna för Windows, ingen källkod.
*This page only holds the Windows installers, no source code.*

---

## Svenska

### Installera

1. Öppna [senaste versionen](https://github.com/intothenether/Facio-Install/releases/latest).
2. Hämta filen som heter `Facio-Setup-…exe` under **Assets**.
3. Kör filen och följ installationsguiden.

Windows kan visa **"Windows skyddade din dator"** (SmartScreen) eftersom installationsprogrammet ännu inte är signerat. Klicka på **Mer information** och sedan på **Kör ändå**.

### Uppdateringar

Facio letar efter en ny version när programmet startar och frågar dig om du vill hämta den. Inget hämtas utan att du säger ja, och dina fakturor och inställningar finns kvar. Du kan också söka själv under **Inställningar → Uppdateringar**.

### Säkerhetskopiera

Eftersom allt sparas på din dator försvinner det om datorn går sönder. Gör en säkerhetskopia då och då under **Inställningar → Säkerhetskopia**.

## English

### Install

1. Open the [latest release](https://github.com/intothenether/Facio-Install/releases/latest).
2. Download the file called `Facio-Setup-…exe` under **Assets**.
3. Run it and follow the installer.

Windows may show **"Windows protected your PC"** (SmartScreen) because the installer is not code-signed yet. Click **More info**, then **Run anyway**.

### Updates

Facio looks for a new version when it starts and asks whether you want to download it. Nothing is downloaded without your say-so, and your invoices and settings are kept. You can also check yourself under **Settings → Updates**.

### Back up

Because everything is kept on your computer, it is lost if the computer fails. Make a backup now and then under **Settings → Backup**.
